An open-source JPEG-LS encoder IP core for real-time lossless image compression on FPGA.

VHDL ISO/IEC 14495-1 Vendor-agnostic v1.5.1

OpenJLS implements the JPEG-LS standard — a low-complexity lossless image codec reaching ~1.6 : 1 on natural photographs, with no external memory required. It reaches roughly 440 MHz at 12-bit pixel depth on an UltraScale+ ZU7EG, the MPSoC family used in onboard processors such as the Xiphos Q8, and processes one pixel per clock. The whole project is open source — the RTL, the testbenches and the verification flow are all public.

It handles single-component (grayscale) data, so a multi-band sensor uses one compressor per band — resource usage is low enough to run every band in parallel. The core is vendor-agnostic, targeting any FPGA platform.

2Architecture

OpenJLS follows the JPEG-LS encoding pipeline, implemented as a fully pipelined, vendor-agnostic VHDL core.

1Gradient computation

Local gradients from the causal neighbors a, b, c, d.

2Context modeling

Gradient quantization into 365 contexts.

3Prediction

MED predictor with per-context bias correction.

4Encoding

Adaptive Golomb-Rice, run-length for uniform regions.

5Bitstream packing

Bit packing, byte stuffing and framing into an ISO/IEC 14495-1 stream.

3.1Image width sweep

MAX_IMAGE_WIDTH from 4k to 64k pixels, at 12-bit grayscale. It sizes the line buffer, so only block RAM follows it.

3.2Pixel depth sweep

BITNESS from 8 to 16 bits, at a maximum image width of 12,288. It widens the datapath.

All figures characterized on an UltraScale+ xczu7eg-fbvb900-1-e (speed grade −1, slowest), Vivado 2025.2. Frequencies are true fmax — read by over-constraining the clock until the design failed timing. Resource figures use the default strategy; utilization is near-identical across strategies. RTL only, no floorplanning or vendor-specific optimization: representative, not guaranteed.

4Verification

Verified at three levels. In simulation, a layered suite — constrained-random self-checking tests, functional coverage, code coverage, and byte-exact comparison against CharLS, an independent open-source implementation of JPEG-LS — runs at both RTL and post-synthesis gate level. The same corpus is then re-encoded on a real device: the core runs on a PYNQ-Z2 and the returned bitstreams are compared byte-for-byte against the same reference. Formal proofs cover the control logic, the T.87 arithmetic and the bit/byte streams.
